# packaging/ — inputs for build_packages.py

`../build_packages.py` turns a harmonized findings corpus into N self-contained deposit packages
(data/ docs/ qa/ code/ deposit/ annotations/, MANIFEST.json with per-file SHA-256, CHECKSUMS.sha256,
CITATION.cff, .zenodo.json, a verifier with planted regressions) plus per-package tarballs and a
repository tree. It was reconstructed on 2026-09-16 from the POTS build and reproduces that build's
v1 packages byte-for-byte (219/220 files; the one difference was a v1 defect, see the pots-corpus
REBUILD_REPORT).

- `package_config.pots_dysautonomia.json` — the POTS build's package metadata, declared inputs (by
  artifact id or local path), the Tier-2 wave split, and pinned gzip mtimes. Copy and edit for a new area.
- `templates/` — `prose.json` (hand-written passages the generator interpolates; `column_descriptions`,
  `code_roles`, `annotation_descriptions`), verbatim files (LICENSE, COMPARABILITY.md, verify_package.py,
  gitignore) and `@@PLACEHOLDER@@` templates for the root README, OVERVIEW, PUBLISHING and CITATION.

```
python build_packages.py --config packaging/package_config.<area>.json --corpus findings.parquet \
    --inputs-dir inputs --templates packaging/templates --out build --version v1 \
    --docs-revision v1.1 --dtype-fix [--annotations annotations/] [--backfill-doi tier1=10.xxxx/...]
```

Rules the script honours: flag, never silently repair; never mutate tier data (annotations are
additive files); every documented number is recomputed from the data on each build and checked by
the shipped verifier; checksums are generated by the script, never by hand.
